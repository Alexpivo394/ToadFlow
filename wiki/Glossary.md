# Словарь

| Термин | Что значит |
|---|---|
| **Агент** | Программа ToadFlow на Windows-машине с Revit. Получает задания от сервера, запускает Revit и следит за ним. См. [Установка агента](Agent) |
| **Аддин** | Надстройка ToadFlow в Revit. Работает только в Revit, который запустил агент |
| **Аналитика LOI** | Страница с графиками заполненности по объектам, разделам и моделям. См. [Аналитика LOI](Analytics). Одноимённый раздел настроек — включение аналитики и разбор имён моделей |
| **База для дашбордов** | Книга Excel, куда каждая проверенная модель дописывает свои итоги — для Power BI. Задаётся в расписании LOI |
| **Заполненность** | Доля заполненных значений среди всех проверенных (элементы × параметры) |
| **Запуск** | Одно срабатывание расписания: по времени, вручную или повтор упавших. Состоит из заданий — по одному на модель |
| **Задание** | Обработка одной модели в одном запуске: выгрузка или проверка |
| **Исключение** | В расписании LOI — свой профиль для конкретной модели, главнее раздела и профиля расписания |
| **Группа профилей** | Папка для профилей LOI, обычно проект. Имя профиля уникально внутри группы; в отчётах профиль подписан «Группа · Имя» |
| **Источник** | Откуда расписание берёт модели: Revit Server или сетевая папка |
| **Каталог Revit** | Список категорий и параметров, снятый в Revit на агенте. Нужен редактору правил для подписей и подсказок |
| **Кусок имени** | Часть имени модели между разделителями: в `PLK_K2_OV` куски `PLK`, `K2`, `OV` |
| **LOI** | Level of information — уровень информационного наполнения: насколько заполнены параметры элементов |
| **Нет параметра** | У элемента и его типа нет проверяемого параметра. Считается незаполненным значением |
| **Остальные модели** | В расписании «по разделу модели» — модели, раздел которых не распознан или не назначен. Проверяются отдельным профилем или пропускаются |
| **Папка результатов** | Куда расписание кладёт RVT, NWC или отчёты LOI |
| **Полнота** | Доля элементов, у которых заполнены все проверяемые параметры |
| **Пресет выгрузки** | Именованный набор параметров RVT и NWC |
| **Профиль LOI** | Набор правил проверки. Тот же формат, что у плагина ParamChecker. См. [Профили LOI](LOI-profiles) |
| **Правило** | Часть профиля: какие элементы отобрать и какие параметры у них проверить. В отчёте — отдельный лист |
| **Пусто** | Параметр у элемента есть, но значение не заполнено |
| **Раздел** | Раздел проекта: АР, КР, ОВ, ВК… Определяется из имени модели справочником именования |
| **Разделитель** | Символ, по которому имя модели режется на куски, обычно `_` |
| **Ручная поправка** | Объект, раздел, часть или заказчик, заданные конкретной модели вручную. Главнее справочника |
| **Свои поля** | Поля справочника именования сверх объекта, раздела и части — например «Стадия». Есть фильтры по ним в аналитике |
| **Справочник именования** | Настройки разбора имён моделей: записи, шаблоны кусков, выражения на имя целиком. См. [Разбор имён моделей](Model-naming) |
| **Токен доступа** | Личный ключ, с которым программа (например, ParamChecker) работает с ToadFlow от имени пользователя |
| **ФОП** | Файл общих параметров Revit. Если он подключён в Revit на агенте, каталог содержит ADSK-параметры |
| **Часть здания** | Корпус, секция, блок — то, что распознают шаблоны кусков |
| **Шаблон куска** | Регулярное выражение, которое распознаёт класс кусков имени: `K1`, `K12` → «корпус 1», «корпус 12» |
| **Экземпляр Revit** | Один запущенный агентом Revit. Сколько их одновременно на машине, задают лимиты агента |
