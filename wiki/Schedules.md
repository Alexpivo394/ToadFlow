# Расписания

Расписание отвечает на вопросы: **что** выгружать, **откуда**, **куда** и **как часто**. Список расписаний показывает следующий запуск, автора и того, кто менял расписание последним.

Создавать и менять расписания могут операторы и администраторы.

## Вкладка «Настройка»

| Поле | Что задаёт |
|---|---|
| **Название** | Имя в списке и в истории; подставляется в папку результатов как `{расписание}` |
| **Источник** | Revit Server или сетевая папка из **Настройки → Источники** |
| **Папка результатов** | Куда класть RVT и NWC. Подстановки: `{расписание}`, `{дата}` (ГГГГ-ММ-ДД), `{время}` (ЧЧ-ММ) — по часовому поясу из **Настройки → Общие**. Пример: `\\nas\Выгрузки\{расписание}\{дата}` |
| **Когда** | **По дням недели** в заданное время, **каждые N часов** начиная с заданного времени или **один раз** |
| **Приоритет** | Низкий, обычный или высокий — кто первым получает свободный Revit |
| **Таймаут на модель, мин** | Дольше этого модель не выгружается: Revit убивается, модель считается упавшей |
| **Повторять упавшие** | Сколько раз повторить модель, если упал или завис Revit либо пропала связь с агентом. Ошибки самой модели (нет 3D-вида, модель повреждена) не повторяются |

Выключенное расписание не запускается по времени, но его можно запустить вручную.

## Вкладка «Модели»

Дерево источника с колонками **RVT** и **NWC**. Галочка на папке отмечает всё её содержимое.

Флажок **«Добавлять новые модели из отмеченных папок»**: при каждом запуске папка разворачивается заново, и модели, появившиеся в ней позже, тоже выгружаются. Без флажка выгружается только то, что было в папке при сохранении.

## Вкладка «Параметры RVT / NWC»

Пресет выгрузки и переопределения его параметров только для этого расписания.

> [!NOTE]
> Модель с NWC берёт только агент, у которого для её версии Revit установлен Navisworks Exporter. Если такого агента нет, модель ждёт в очереди.

После сохранения расписание предупреждает о том, что заведомо помешает выгрузке: для версии Revit источника нет ни одного агента, или у моделей одинаковые имена файлов и они перезапишут друг друга в папке результатов.

## Вкладка «История изменений»

Кто и когда менял расписание и что именно поменялось: папку, модели, время, пресет и так далее.

## Запуск вручную

Кнопка **«Запустить сейчас»** создаёт запуск сразу, не дожидаясь времени по расписанию. В истории такой запуск помечен именем того, кто его запустил.

## Версии Revit

Модель всегда открывается в Revit той версии, в которой она сохранена, и не обновляется. Для Revit Server версия задана в источнике; для сетевой папки агент читает её из каждого файла. Если ни на одном агенте нет нужной версии, модель ждёт в очереди с пометкой **«ждёт Revit 20NN»**.
