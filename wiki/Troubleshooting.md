# Частые проблемы

## Агент

| Признак | Причина и решение |
|---|---|
| Агент **«не в сети»** | Машина не видит адрес сервера, или пользователь агента не вошёл в Windows. Откройте адрес сервера в браузере на этой машине; проверьте автоматический вход и значок ToadFlow в области уведомлений |
| В подсказке значка **«нет связи с сервером»** | То же; подробности — в логах агента (меню значка → **Папка логов**) |
| Агент не появляется после установки | Код подключения одноразовый и действует 24 часа. Получите новый в **Настройки → Агенты → Подключить агента** и зарегистрируйте агента ещё раз: [Регистрация из командной строки](Agent#регистрация-из-командной-строки) |
| Агент **«устарел»** | Сервер обновили, агент — нет. Поставьте MSI из последнего [релиза](https://github.com/Alexpivo394/ToadFlow/releases) |
| Найдены не все версии Revit | Агент ищет Revit по записям установки Windows. Revit, поставленный копированием папки, не находится |

## Revit

| Признак | Причина и решение |
|---|---|
| Revit стартует и стоит на окне «Надстройка без подписи» | Агент отвечает на это окно сам, если Revit запустил он. Если окно висит — обновите агента до 1.0.3 или новее; в логе агента должна быть строка «ответ «Всегда загружать»» |
| Revit сообщает о повторяющемся AddInId | Аддин ToadFlow лежит ещё и в `%AppData%\Autodesk\Revit\Addins\20NN` — например, от отладочной сборки. Удалите его оттуда |
| Revit не запускается: «не запустился за 5 мин» | Revit ждёт ответа в каком-то окне (лицензия, обновление, первый запуск). Зайдите на машину под пользователем агента, запустите эту версию Revit руками и закройте все вопросы |
| Revit убивается с причиной **«не отвечал N мин»** | Revit завис или долго молчит на очень тяжёлой модели. Модель повторится, если у расписания остались попытки. Для тяжёлых моделей увеличьте **Молчание Revit до перезапуска** в **Настройки → Общие** |
| Revit убивается с причиной **«превышен таймаут»** | Модель выгружается дольше таймаута расписания. Увеличьте **Таймаут на модель** в расписании |
| «A managed exception was thrown by Revit or by one of its external applications» | Внутренняя ошибка Revit или другого аддина, установленного в этот Revit, — модель тут ни при чём. Агент перезапускает Revit и повторяет модель, если у расписания остались попытки. Если ошибка частая, отключите в Revit на машине с агентом лишние аддины (их манифесты `.addin` лежат в `%ProgramData%\Autodesk\Revit\Addins\20NN` и `%AppData%\Autodesk\Revit\Addins\20NN`) |

## Модели

| Признак | Причина и решение |
|---|---|
| Модель **«ждёт Revit 20NN»** | Ни на одном агенте в сети нет Revit этой версии, у него лимит экземпляров 0 или для NWC нет Navisworks Exporter. Поставьте нужную версию на одну из машин или поднимите лимит в **Настройки → Агенты** |
| Модель сохранена в более новой версии Revit, чем указано в источнике | Модель не открывается и не обновляется — так задумано. Для Revit Server проверьте версию источника; для папки версия берётся из файла |
| NWC пропущен: нет вида | В модели нет 3D-вида с именем из пресета (по умолчанию `Navisworks`). Создайте вид или поменяйте имя в пресете |
| NWC пропущен: на виде нет видимых элементов модели | Вид пуст при тех настройках открытия, с которыми выгружалась модель. Часто на виде только связи, а связи не загружались (**Не загружать связи** в пресете), или элементы лежат в рабочих наборах, закрытых словом из **Не открывать рабочие наборы, содержащие**. Поправьте вид или пресет |
| NWC: Navisworks Exporter не создал файл | Экспортер отработал без ошибки, но файла нет. Проверьте вид в модели и место на диске папки результатов; повторите модель |
| NWC пропущен: Navisworks Exporter не установлен | Поставьте Navisworks Exporter для этой версии Revit на машину с агентом |
| Ошибка доступа к папке | Пользователь агента не имеет прав на чтение папки модели или на запись в папку результатов. Проверьте права именно этого пользователя Windows |
| Файлы в папке результатов перезаписывают друг друга | У моделей одинаковые имена файлов. Расписание предупреждает об этом после сохранения; разнесите модели по разным расписаниям или добавьте `{расписание}` в папку результатов |

## Сервер

| Признак | Причина и решение |
|---|---|
| Интерфейс не открывается | `docker compose ps` — все ли сервисы запущены; `docker compose logs server` — ошибки сервера. Частая причина — не заполнены переменные в `.env` |
| После обновления все вышли из системы | Изменился `JWT_KEY` в `.env`. Войдите заново |
| Интерфейс открывается, но данные не обновляются сами | Обратный прокси не пропускает WebSocket на `/hubs/` — см. [HTTPS](Server#https) |
| Забыт пароль администратора | Если есть другой администратор — **Настройки → Пользователи → Сбросить пароль**. Если нет — восстановите базу из резервной копии или заведите нового администратора на пустой базе |
