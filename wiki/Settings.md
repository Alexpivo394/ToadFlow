## Агенты

Машины с Revit, на которых стоит агент ToadFlow.

| Колонка | Что показывает |
|---|---|
| **Машина**, **Статус** | Имя компьютера; **в сети**, **не берёт новые**, **нет связи** или **отключён** |
| **Версия агента** | Пометка **«устарел»** — агент старше сервера, его стоит обновить |
| **Найденные Revit** | Какие версии Revit агент нашёл и есть ли для них Navisworks Exporter |
| **Экземпляров (макс.)** | Сколько Revit каждой версии агент держит одновременно (кнопка **«Изменить»**); общее число на машину — сумма по версиям, ограничено только памятью машины |

Действия:

- **Подключить агента** — одноразовый код для установки агента, см. [Установка агента](Agent).
- **Не брать новые / Брать новые** — агент доделывает текущие выгрузки и не берёт новые. Нужно перед обновлением или обслуживанием машины.
- **Отключить** — агент больше не сможет подключиться к серверу. Чтобы вернуть машину, удалите агента и подключите заново кодом.
- **Удалить** — для агента без связи или отключённого: он пропадает из списка, история его выгрузок остаётся.

## Источники

Откуда расписания берут модели. Дерево источника читает агент, поэтому адрес должен быть доступен с машин с Revit.

| Тип | Поля |
|---|---|
| **Revit Server** | **Имя или адрес Revit Server** (например `srv-rs22`), **Версия Revit** — сервер обслуживает одну версию, **Корневая папка на сервере** — пусто, чтобы видеть весь сервер |
| **Сетевая папка** | **Папка** — UNC-путь, например `\\nas\Проекты`. Версия Revit берётся из каждого файла |

## Пресеты выгрузки

Именованные наборы параметров RVT и NWC. Один пресет — **по умолчанию**: он подставляется в новое расписание. Расписание может переопределить любой параметр пресета для себя.

**Открытие**

| Параметр | Что делает |
|---|---|
| **Не загружать связи** | Модель копируется во временную папку агента, в копии связи помечаются «не загружать». Открытие быстрее, исходник не меняется |
| **Проверка при открытии (Audit)** | Revit проверяет и исправляет модель при открытии — заметно дольше |
| **Не открывать рабочие наборы, содержащие** | Рабочие наборы с этим словом в имени остаются закрытыми; их элементов нет в NWC |

**RVT — обработка перед сохранением:** удалить связи RVT, удалить CAD, удалить облака точек, очистить неиспользуемое (доступно с Revit 2024), сжать файл. Модели совместной работы сохраняются как отсоединённые файлы хранилища с локальной копией.

**NWC:** имя 3D-вида для экспорта (по умолчанию `Navisworks`), общие координаты, параметры элементов, разделение по уровням, связанные файлы и CAD, части, геометрия помещений и помещения как атрибут, источники света, идентификаторы элементов, ссылки (URL), поиск отсутствующих материалов, коэффициент фасетизации. Если в модели нет вида с заданным именем, NWC пропускается с пояснением в истории.

## Профили LOI

Правила проверки заполнения параметров — те же профили, что в плагине ParamChecker. Меняют их операторы и администраторы.

- **Загрузить из ParamChecker** — добавить профили из файла плагина. Одноимённые получают номер, ничего не перезаписывается; модели из файла не переносятся.
- **+ Новый профиль** и щелчок по профилю — редактор: вид по умолчанию, рабочие наборы, которые не открывать, и правила (какие элементы отобрать и какие параметры у них проверить).
- **Группы** — профили раскладываются по группам, обычно по проектам; внутри группы имена уникальны. Группу можно переименовать целиком, профиль — скопировать в другую группу.
- **Скачать** — файл с одним профилем, который плагин импортирует обратно.
- **Удалить** — профиль, который выбран хотя бы в одном расписании, удалить нельзя.
- **готов / не готов** — можно ли проверять этим профилем; на пометке «не готов» написано, чего не хватает.
- **Каталог Revit для редактора правил** — внизу страницы: кнопка **«Обновить из Revit»** снимает категории и параметры в Revit на агенте, чтобы редактор подсказывал названия.

Подробно, с примерами правил и операторов — [Профили LOI](LOI-profiles).

## Аналитика LOI

> [!NOTE]
> Это настройки. Страница с графиками — **Аналитика LOI** в главном меню, см. [Аналитика LOI](Analytics).

Смотреть может любой пользователь, менять — только администратор. На странице три блока:

| Блок | Что там | Подробно |
|---|---|---|
| **Аналитика LOI** | Флажок **«Сохранять итоги проверок и показывать аналитику»**, **«Хранить проверки, лет»** (0 — всегда) и кнопка **«Пересчитать аналитику по справочнику»** | [Аналитика LOI](Analytics#включить-выключить-срок-хранения) |
| **Разбор имён моделей** | Справочник: как из имени модели получить объект, раздел, часть здания и свои поля. Разделители, записи по полям, шаблоны кусков, выражения на имя целиком, предпросмотр и кнопка «Стандартный справочник» | [Разбор имён моделей](Model-naming) |
| **Ручные поправки моделей** | Объект, раздел, часть или заказчик конкретной модели — главнее справочника | [Ручные поправки](Model-naming#ручные-поправки-моделей) |

## Токены доступа

Личные токены — у каждого пользователя свои. С токеном программа (например, плагин ParamChecker) работает с ToadFlow от вашего имени и с вашими правами; программа передаёт его в заголовке `X-ToadFlow-Token`. Сам токен показывается один раз при создании — храните его как пароль. В списке видно, когда токен использовался последний раз; ненужный — **Отозвать**. Управлять токенами можно только после входа паролем, не другим токеном.

## Пользователи

| Роль | Что может |
|---|---|
| **Наблюдатель** | Смотрит дашборд, расписания и историю |
| **Оператор** | Плюс расписания, пресеты и профили LOI, запуск, отмена и повтор заданий, «Убить» Revit |
| **Администратор** | Плюс агенты, источники, пользователи и общие настройки |

Администратор создаёт пользователей, меняет роль, сбрасывает пароль и отключает учётную запись. Пароль — не короче 6 символов.

## Общие

| Параметр | По умолчанию | Что задаёт |
|---|---|---|
| **Часовой пояс** | Europe/Moscow | По нему считаются расписания, дни на графике и `{дата}` в папке результатов |
| **Таймаут на модель по умолчанию, мин** | 30 | Подставляется в новые расписания |
| **Молчание Revit до перезапуска, мин** | 10 | Revit, который столько не подаёт признаков жизни, считается зависшим: агент убивает его, модель повторяется |
| **Перезапускать Revit после, моделей** | 20 | Плановый перезапуск Revit, чтобы не копились утечки памяти |
| **Или когда Revit занял, МБ** | 12000 | То же — по занятой памяти |
| **Хранить логи, дней** | 90 | Сколько хранить закончившиеся запуски, их логи и события системы |

Изменения сразу отправляются всем агентам.
