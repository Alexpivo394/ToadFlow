# Установка агента

Агент ставится на Windows-машину с Revit. Он получает задания от сервера, запускает до трёх экземпляров Revit и выгружает модели через аддин ToadFlow. Соединение с сервером агент открывает сам, входящие порты на машине не нужны.

## Что нужно

| Что | Зачем |
|---|---|
| Windows 10 или 11, x64 | Агент и Revit |
| Revit тех версий, в которых сохранены модели (2020–2027) | Модель открывается только в Revit своей версии. Модель без подходящего Revit ждёт в очереди |
| Navisworks Exporter для каждой версии Revit, где нужен NWC | Без него задания с NWC эта машина не берёт |
| Пользователь Windows с автоматическим входом | Агент и Revit работают в сессии пользователя, а не службой: Revit не запускается без рабочего стола |
| Доступ этого пользователя к папкам моделей и к сетевой папке результатов | Revit читает модели и пишет результаты от имени пользователя |
| Доступ к адресу сервера ToadFlow, например `http://toadflow:8080` | Связь с сервером |

.NET отдельно ставить не нужно — всё, что нужно агенту, уже в установщике.

> [!TIP]
> Удобнее всего завести под агента отдельного пользователя Windows, выдать ему права на папки и лицензию Revit и включить для него автоматический вход: `netplwiz` или [Autologon](https://learn.microsoft.com/sysinternals/downloads/autologon) от Sysinternals. После перезагрузки машина сама войдёт в Windows, и агент стартует из автозапуска.

## Установка

Установщик `ToadFlowAgent-<версия>.msi` прикреплён к каждому [релизу на GitHub](https://github.com/Alexpivo394/ToadFlow/releases).

1. В веб-интерфейсе откройте **Настройки → Агенты → Подключить агента**. Сервер выдаст одноразовый код вида `TF-XXXX-XXXX`.
2. На машине с Revit, от администратора:

   ```powershell
   msiexec /i ToadFlowAgent-1.0.0.msi SERVER=http://toadflow:8080 CODE=TF-XXXX-XXXX
   ```

   Можно и просто запустить MSI двойным щелчком — тогда адрес сервера и код агент спросит в окне **«Подключение к ToadFlow»** при первом запуске.
3. Войдите в Windows под пользователем агента (или запустите **ToadFlow Agent** из меню «Пуск»).
   Через несколько секунд агент появится в **Настройки → Агенты** в состоянии **«в сети»**, со списком найденных версий Revit.

| Свойство MSI | Что делает |
|---|---|
| `SERVER` | Адрес сервера, как его открывают в браузере |
| `CODE` | Код подключения из **Настройки → Агенты** |

Если код неверный или устарел, установка всё равно пройдёт, а агент при первом запуске покажет окно подключения.

### Что и куда ставится

| Что | Куда |
|---|---|
| Агент | `%ProgramFiles%\ToadFlow\Agent` |
| Аддин для Revit 2020–2026 | `%ProgramData%\Autodesk\Revit\Addins\20NN` |
| Аддин для Revit 2027 | `%ProgramFiles%\Autodesk\Revit\Addins\2027` |
| Автозапуск при входе любого пользователя | `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`, значение `ToadFlowAgent` |
| Ярлык | Меню «Пуск» → ToadFlow |
| Конфигурация | `%ProgramData%\ToadFlow\Agent\agent.json` — ключ агента зашифрован ключом машины, на другом компьютере файл не работает |
| Логи | `%ProgramData%\ToadFlow\Agent\logs` — файл на каждый день, хранятся 14 дней |

### Надстройка без подписи

Аддин ToadFlow не подписан, и Revit при запуске показывает окно **«Безопасность — Надстройка без подписи»**. Настраивать ничего не нужно: агент находит это окно в Revit, который запустил сам, и нажимает **«Всегда загружать»**. В логе агента это строка «спросил про неподписанный аддин ToadFlow — ответ «Всегда загружать»».

Revit, открытый на этой машине руками, агент не трогает: там окно, как обычно, ждёт ответа пользователя.

## Значок в области уведомлений

Подсказка значка показывает состояние: `ToadFlow · в сети · Revit: 2 · выгружает АР.rvt`. Меню:

- **Открыть ToadFlow** — веб-интерфейс в браузере;
- **Папка логов**;
- **Выход** — если идёт выгрузка, агент спросит подтверждение: Revit будет закрыт, а задание повторится позже.

## Регистрация из командной строки

```powershell
& "$env:ProgramFiles\ToadFlow\Agent\ToadFlow.Agent.exe" --register --server http://toadflow:8080 --code TF-XXXX-XXXX
```

| Код выхода | Значение |
|---|---|
| 0 | Агент зарегистрирован |
| 1 | Сервер недоступен или код недействителен |
| 2 | Не указан `--server` или `--code` |

Повторная регистрация заменяет конфигурацию — так агента переносят на другой сервер. Перед этим закройте агента (**Выход** в меню значка) и запустите снова после регистрации.

## Обновление и удаление

1. В **Настройки → Агенты** нажмите **«Не брать новые»** у агента: он доделает текущие выгрузки и больше ничего не возьмёт.
2. Поставьте новый MSI поверх старого. Конфигурация и логи сохраняются.
3. Нажмите **«Брать новые»**.

Удаление — **Параметры → Приложения → ToadFlow Agent**. Конфигурация и логи в `%ProgramData%\ToadFlow\Agent` остаются; агента в веб-интерфейсе удалите вручную.

## Проверка работы

- Значок ToadFlow в области уведомлений, в подсказке — «в сети».
- **Настройки → Агенты**: агент в сети, версии Revit и наличие Navisworks Exporter совпадают с установленными.
- Расписание на одну модель и **«Запустить сейчас»**: агент запускает Revit, в истории появляется пошаговый лог, результат лежит в папке результатов.

Если что-то не так — [Частые проблемы](Troubleshooting).
